Changelog

Notable Formalint updates and site quality changes.

August 31, 2026 - Auth Webhook and Pagination Guides

Added OAuth/JWT debugging, webhook debugging and API pagination debugging guides. Expanded API Debugging navigation so visitors can investigate 401/403 token failures, webhook delivery evidence and missing or duplicated paginated API results from one workspace.

August 31, 2026 - Contract Security and Rate Limit Guides

Added OpenAPI contract review, HTTP security headers and API rate limit debugging guides. Expanded API Debugging navigation so visitors can move from curl evidence into contract drift, browser security policy and 429 quota analysis.

August 31, 2026 - API Evidence Library Expansion

Added curl API debugging, CORS debugging and HTTP Cache-Control guides. Connected the pages into the API Debugging sidebar mode, command palette, home portal, tools directory, guides directory and sitemap so developers can move from browser symptoms into reproducible request evidence.

August 31, 2026 - DBA Cache and Proxy Expansion

Added MySQL DBA checks, Redis debugging checks and an Nginx reverse proxy checklist. Expanded Database Ops and Shell Ops navigation so developers can move from API symptoms into database, cache and proxy evidence without leaving Formalint.

August 31, 2026 - Runtime and Database Ops Expansion

Added Node.js runtime checks, Docker Compose debugging and a PostgreSQL DBA checklist. Expanded the left console with a Database Ops mode, connected new pages into the home page, tools directory, guides directory and sitemap, and kept the runtime group aligned across PHP, Java, Python and Node.js.

August 28, 2026 - DBA and Admin Library Update

Expanded Formalint with a DBA and operations reference layer. Added guides for DBA administration, terminal workflows, Linux Cockpit setup, Windows administration commands, Linux administration commands, PHP runtime checks, Java runtime checks, Python runtime checks and hardware diagnostics. Updated the sidebar console, command palette, tools directory, guides directory and sitemap so developers can move between formatters, runtime checks and admin workflows.

August 28, 2026 - Sidebar Accordion Update

Changed the left developer console into a collapsed-by-default accordion so visitors first see clean category headings, then expand the exact workspace they need. Search now opens only matching groups, and runtime navigation now includes Python beside PHP and Java.

August 27, 2026 - Console UI Update

Moved Formalint toward a darker developer-console interface with a compact first viewport, immediate access to the JSON workspace, refreshed tool cards and cache-busted stylesheet loading across public HTML pages.

August 27, 2026 - Resource Hub Update

Expanded Formalint from a tool collection into a stronger developer resource hub. The home page now shows quality signals, operating principles, a reference library, maintained-site indicators and clearer routes into high-value guide content. Added long-form guides for developer data validation and formatter/linter/validator decisions.

August 27, 2026 - Content Quality Update

Added cornerstone guides for regex, data formats and API debugging. Added transparency pages for editorial policy, local-first behavior and changelog visibility. Improved the home page structure so Formalint reads more clearly as a developer tools and reference site.

July 28, 2026

Added focused regex references for email validation, URL validation, UUID v4 validation, date validation and log parsing. Updated Search Console-oriented internal links and sitemap entries.

July 2026

Added XML linting, YAML indentation, SQL cleanup and Python indentation references. Expanded the developer tools directory and strengthened cross-links between related tools.
